### Now building: Yuki

**Your AI, in your chat. It works with you, or keeps you company.** Open it and Yuki is already there: tell it who to be in one sentence, then raise it your way. Add more when you want help and put them in a group; they hand work to each other where you can see it, and come to you only when something needs your decision. The core is source-available, so you can run it on your own machine.

**住在聊天里的 AI，能帮你干活，也能陪着你。** 打开就有 Yuki，一句话告诉它做谁，越养越懂你；需要帮手就再加几个、拉进群，它们在对话里互相交接，只有要你拍板的事才来找你。核心源码公开，可以跑在你自己的电脑上。

**チャットに住む、あなたのAI。** 仕事を手伝い、そばにもいてくれる。ひとことで性格を決めて、「うちの子」に育てよう。
